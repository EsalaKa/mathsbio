Intracellular stochasticity

Molecular events inside a cell occur randomly. When molecule numbers are small, this randomness can produce substantial variation between otherwise similar cells.

A reaction such as

\[A\xrightarrow{k}B\]

can therefore be modelled as a random event with a rate determined by the current molecular state.

Deterministic versus stochastic description

ODE models describe average concentration changes continuously. Stochastic reaction models represent discrete reaction events and random waiting times.

The Gillespie stochastic simulation algorithm is a standard method for generating individual trajectories of such reaction networks.

Key idea. Intracellular noise is not merely measurement error; randomness in molecular reaction events can itself influence cellular behaviour.
