Writing the deterministic SIR equations

The SIR flow diagram describes who moves between compartments. The differential equations describe the instantaneous rate of change of each compartment. Here we translate those equations directly into a reusable Python function.

Biological scenario

An epidemic is observed when 900 people are susceptible, 80 are infectious and 20 have recovered. The population is closed, with transmission parameter \(\beta=0.3\) and recovery-rate parameter \(\gamma=0.1\).

At this particular state, is each compartment increasing or decreasing, and how rapidly?

The deterministic SIR equations

Susceptible

\[\frac{dS}{dt}=-\beta\frac{SI}{N}\]

Infectious

\[\frac{dI}{dt}=\beta\frac{SI}{N}-\gamma I\]

Recovered

\[\frac{dR}{dt}=\gamma I\]

The derivatives \(\frac{dS}{dt}\), \(\frac{dI}{dt}\) and \(\frac{dR}{dt}\) are instantaneous rates of change. They describe the direction and speed of change at the current state; they do not yet calculate the complete epidemic through time.

Adding the three equations gives

\[\frac{dS}{dt}+\frac{dI}{dt}+\frac{dR}{dt}=0.\]

Therefore, \(N=S+I+R\) remains constant.

Programming objective

We will write a Python function named sir_rates. It will receive the current compartment sizes and parameters, then return the three SIR rates of change.

Translate the mathematics into Python

Build the function step by step

Step 1: Define the function

def sir_rates(S, I, R, beta, gamma):

def begins a function definition. The function name is sir_rates. The names inside the parentheses are parameters of the Python function: values must be supplied when the function is called.

Step 2: Calculate quantities inside the function

    N = S + I + R
    infection_flow = beta * S * I / N
    recovery_flow = gamma * I

The four spaces create an indented function body. These calculations belong to the function and use the values passed into it.

Step 3: Form the three derivatives

    dS_dt = -infection_flow
    dI_dt = infection_flow - recovery_flow
    dR_dt = recovery_flow

Each Python statement corresponds to one deterministic SIR equation.

Step 4: Return the results

    return dS_dt, dI_dt, dR_dt

return sends three calculated values back to the part of the program that called the function.

Step 5: Call the function

dS_dt, dI_dt, dR_dt = sir_rates(S, I, R, beta, gamma)

The supplied arguments are matched by position. The three returned values are assigned to three variable names in the same order.

Run the complete program

Change the epidemic state or parameters, then run the program. The function calculates the instantaneous rates at the values you supply.

Biological interpretation

At this epidemic state, the infection flow is 21.6 people per day and the recovery flow is 8 people per day. The infectious population therefore has a positive net rate of \(21.6-8=13.6\) people per day.

This does not mean that the compartments will continue changing at these fixed rates. As \(S\) and \(I\) change, the function must be evaluated again at the new state. A numerical method repeatedly performs that calculation to construct the epidemic trajectory.

Function and model conditions

  • The function requires five arguments in the order S, I, R, beta, gamma.
  • The total population must be positive because the infection term divides by \(N\).
  • Compartments and rate parameters cannot be negative.
  • The function returns rates, not updated compartment sizes.
  • The derivative sum should be zero in this closed SIR model.
  • The triple quotation marks create a short function description called a docstring.
