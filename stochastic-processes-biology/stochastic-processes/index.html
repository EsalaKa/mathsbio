Stochastic processes

A random variable describes an uncertain numerical quantity. Biological systems, however, usually change through time. A stochastic process extends the idea of a random variable so that we can describe an uncertain state at every time of interest.

Core idea. A stochastic process describes how a random state evolves through time. At each time there is a random variable; together, these random variables describe the whole random evolution of the system.

From one random variable to a process

Suppose

\[I(10)=\text{number of infectious individuals on day 10}.\]

This is one random variable. Before observing the epidemic, we do not know whether \(I(10)\) will be 0, 4, 20 or another possible value.

But we may want to describe the infectious population throughout the epidemic:

\[I(0),\ I(1),\ I(2),\ I(3),\ldots\]

or, if time is continuous,

\[I(t),\qquad t\geq0.\]

The collection of these time-indexed random variables is a stochastic process.

one time→one random variable \(I(10)\)→many times→stochastic process \(I(t)\)

Formal notation

A stochastic process is commonly written

\[\boxed{\{X(t):t\in T\}}.\]
SymbolMeaning
\(X(t)\)the random state of the system at time \(t\)
\(t\)a particular time
\(T\)the set of times considered
\(\{X(t):t\in T\}\)the complete stochastic process

For every fixed time \(t\), \(X(t)\) is a random variable.

Example. If \(X(t)=I(t)\), then \(I(5)\) is the random number infectious on day 5, \(I(20)\) is the random number infectious on day 20, and the complete collection \(I(t)\) describes how the infectious population evolves.

Why is \(X(t)\) random?

Imagine repeating the same epidemic many times with the same initial state and the same model parameters. Random infection and recovery events can occur at different times and in different orders.

Therefore, at day 10, different repetitions may contain different numbers of infectious individuals. So \(I(10)\) has a probability distribution.

The same is true at day 20, day 30, and every other time. The process describes all these linked random quantities.

One process, many possible trajectories

A stochastic process is the probabilistic model. It contains all the possible ways the system may evolve, together with their probabilities.

When one particular sequence of random events occurs, it produces one sample path, also called a realisation or trajectory.

Important distinction. The stochastic process is not one of these curves. It is the probability model that can generate all of them. A trajectory is one realised outcome from that process.

Before and after observing the process

Before an epidemic unfolds, \(I(t)\) is uncertain and is treated as a random variable at each time. After observing one epidemic, we see one particular value at each time.

For example, before day 10 we may have

\[P(I(10)=0)=0.25,\quad P(I(10)=1)=0.10,\quad\ldots\]

After day 10 is observed, that particular epidemic might have

\[I(10)=7.\]

The observed value 7 is one realisation; it does not remove the probability distribution that described what could have happened before observation.

Two kinds of variation must be understood

A stochastic process contains uncertainty in the state at a fixed time and uncertainty in the whole path through time.

If we draw a vertical line at a fixed time \(t\), different trajectories give different values of \(X(t)\). Those values form the probability distribution of the random variable \(X(t)\).

State: what are we tracking?

The state contains the information used to describe the biological system at a particular time.

For a simple SIS epidemic, the state might be only

\[X(t)=I(t),\]

because with a fixed population \(N\),

\[S(t)=N-I(t).\]

For an SEIR epidemic, the state may need several components:

\[\mathbf{X}(t)=\big(S(t),E(t),I(t),R(t)\big).\]

This is a vector-valued stochastic process. Each component is random, and together they describe the epidemic state.

Example. If \(\mathbf{X}(t)=(900,40,35,25)\), then at that instant the realised state contains 900 susceptible, 40 exposed, 35 infectious and 25 recovered individuals.

State space: all states the model allows

The state space is the set of all possible values that the state can take.

If \(I(t)\) counts infectious individuals in a population of size \(N\), then

\[\mathcal{S}=\{0,1,2,\ldots,N\}.\]

For a compartmental epidemic with several counts, a state might be

\[(S,E,I,R),\]

subject to constraints such as

\[S+E+I+R=N.\]
Do not confuse these. The state is where the system is now. The state space is the collection of every state the model permits.

Time can be discrete or continuous

Discrete time

The system is considered at separate times:

\[t=0,1,2,3,\ldots\]

For example, infection counts may be updated once per day.

Continuous time

The system can change at any instant:

\[t\geq0.\]

An infection might occur at time 2.37 days and a recovery at 2.91 days.

Key distinction. Discrete time asks what happens from one scheduled time point to the next. Continuous time allows events to occur whenever their random event times occur.

The state can also be discrete or continuous

Time and state are separate modelling choices.

TimeStateExample
discretediscretenumber infected recorded and updated at daily steps
continuousdiscreteindividual infection and recovery events occurring at arbitrary times
discretecontinuouscontinuous-valued biomass measured at regular time points
continuouscontinuousa continuously varying stochastic concentration or diffusion process

This distinction is fundamental. A continuous-time stochastic process does not necessarily have a continuous-valued state.

Continuous time does not mean a smooth path

This is especially important in epidemic modelling. A continuous-time Markov chain may have continuous time but integer-valued population counts.

If one infection occurs,

\[I\longrightarrow I+1.\]

If one recovery occurs,

\[I\longrightarrow I-1.\]

The event can happen at any continuous time, but the state changes in discrete jumps.

A stochastic process is more than independent random variables

The random variables \(X(1),X(2),X(3),\ldots\) are usually related. What happens today affects what can happen tomorrow.

If an epidemic has 100 infectious people today, its distribution tomorrow will usually be different from the distribution tomorrow if it has only 1 infectious person today.

Therefore a stochastic process must describe not only distributions at individual times, but also the dependence through time.

Why this matters. Simply specifying the distribution of \(X(t)\) separately at every time does not fully describe how trajectories behave. We also need rules connecting the states through time.

Transition probabilities describe movement between states

For a discrete-state process, we are often interested in probabilities such as

\[P(X(t+\Delta t)=j\mid X(t)=i).\]

This reads:

“Given that the system is currently in state \(i\), what is the probability that it is in state \(j\) after time \(\Delta t\)?”

These transition probabilities provide the mathematical rules governing how the stochastic process moves through its state space.

A simple SIS process

Suppose \(I(t)=i\) people are currently infectious. In a simple stochastic SIS model, over a sufficiently short interval \(\Delta t\), three possibilities dominate:

EventNew stateApproximate probability
infection\(i+1\)\(b(i)\Delta t\)
recovery\(i-1\)\(d(i)\Delta t\)
no event\(i\)\(1-[b(i)+d(i)]\Delta t\)

Here \(b(i)\) and \(d(i)\) are event rates when the current state is \(i\).

This simple table already defines the local random behaviour of a continuous-time birth–death-type epidemic process.

Why the current state matters

The infection rate may depend on how many susceptible and infectious individuals currently exist. For example,

\[b(i)=\beta\frac{(N-i)i}{N}.\]

When \(i\) changes, the rate changes. Therefore the future probability law changes with the current state.

This leads naturally to the Markov property: under a Markov model, once the present state is known, earlier history provides no additional information needed to determine the future transition probabilities. That is the subject of the next page.

Expectation of a stochastic process

Because \(X(t)\) is a random variable at each time, it has an expected value:

\[m(t)=E[X(t)].\]

This produces a function of time called the mean function.

Similarly,

\[\operatorname{Var}(X(t))\]

describes how spread out the possible states are at time \(t\).

Important. The mean trajectory \(E[X(t)]\) summarises the process, but it is not the whole stochastic process. Two processes can have similar means but very different variances, extinction probabilities or extreme outcomes.

Dependence between different times

We may also ask how the state at one time is related to the state at another. Quantities such as

\[\operatorname{Cov}(X(s),X(t))\]

measure dependence between the process at times \(s\) and \(t\). This temporal dependence is one reason stochastic-process theory goes beyond ordinary single-variable probability.

What questions can a stochastic process answer?

Once the biological system is represented as a stochastic process, we can ask questions such as

\[P(I(t)=0),\]

the probability infection has disappeared by time \(t\);

\[P\left(\max_t I(t)>K\right),\]

the probability the infectious population exceeds a threshold \(K\); or

\[E[I(t)],\qquad \operatorname{Var}(I(t)),\]

the expected infectious population and its variability through time.

These are questions that a single deterministic trajectory cannot answer by itself.

Process, trajectory and simulation

These three terms are closely related but should not be confused.

TermMeaning
stochastic processthe complete probability model governing random evolution through time
trajectory / sample pathone possible realised evolution of that process
simulationa computational procedure used to generate a trajectory according to the model rules
stochastic model→random events→one simulated trajectory→repeat many times→distribution of outcomes

Where we go next

We now know what a stochastic process is: a random state evolving through time. The next question is how much of the past we need in order to describe its future.

This leads to the Markov property, which provides the foundation for the discrete-time and continuous-time Markov chains developed in the following sections.

Key idea. A stochastic process is a family of connected random variables indexed by time. At each time, the state has a probability distribution; across time, the states are linked by transition rules. One realised history is a trajectory, while the stochastic process describes the entire collection of possible trajectories and their probabilities.
