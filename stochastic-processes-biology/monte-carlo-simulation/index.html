Monte Carlo simulation

A Monte Carlo simulation studies a stochastic model by running it many times and using the collection of outcomes to estimate probabilities, averages, variances and other quantities.

Core idea. One stochastic trajectory shows one possible future. Monte Carlo simulation repeats the stochastic experiment many times so that we can learn the distribution of possible futures.

Why one stochastic trajectory is not enough

Suppose a Gillespie simulation of an epidemic produces a large outbreak. That does not mean a large outbreak is certain. A second run with the same initial state and parameters may die out early.

The model itself describes many possible trajectories. To understand the uncertainty, we need repeated independent runs.

Illustrative independent SIS Gillespie trajectories generated from the same model parameters. Differences between paths come only from different random event sequences.

Monte Carlo as repeated stochastic experiments

Suppose we run the same stochastic model

\[n\]

times. Each run produces a result such as a final epidemic size, a peak infectious count, a time to extinction, or whether a threshold was crossed.

same stochastic model→run 1+run 2+⋯+run n→estimate distribution

Estimating a probability

Suppose we are interested in an event such as

\[A=\{\text{the epidemic reaches at least 30 infectious people}\}.\]

If the event occurs in \(M\) out of \(n\) independent simulations, the Monte Carlo estimate is

\[\boxed{\widehat p=\frac{M}{n}}.\]
Example. If 372 out of 1,000 simulations reach 30 infectious people, then \(\widehat p=372/1000=0.372\). The estimated probability is 37.2%.

Why frequency estimates probability

For each simulation, define an indicator random variable

\[Y_r=\begin{cases}1,&\text{if event }A\text{ occurs in run }r,\\0,&\text{otherwise.}\end{cases}\]

Then

\[\widehat p=\frac1n\sum_{r=1}^nY_r.\]

Since

\[E[Y_r]=P(A)=p,\]

the sample average tends towards the true probability as the number of independent simulations increases.

Estimating an expected value

Suppose each simulation produces a numerical outcome \(Z_r\), such as the epidemic peak. The expectation is estimated by the sample mean

\[\boxed{\widehat{E[Z]}=\frac1n\sum_{r=1}^n Z_r}.\]
Example. If five simulations produce peak infectious counts 12, 18, 9, 21 and 15, the estimated mean peak is \((12+18+9+21+15)/5=15\).

Estimating variance

Monte Carlo simulation can also estimate how variable the outcomes are. If

\[\bar Z=\frac1n\sum_{r=1}^n Z_r,\]

then a common sample-variance estimator is

\[\boxed{s^2=\frac1{n-1}\sum_{r=1}^n(Z_r-\bar Z)^2}.\]

The variance is important because two models can have similar means but very different uncertainty.

A distribution of epidemic peaks

Repeated stochastic simulations produce a collection of peak values rather than one single peak.

Histogram generated from repeated SIS Gillespie simulations. It shows the distribution of peak infectious counts rather than only the average peak.

This is one of the main reasons Monte Carlo simulation is valuable: it reveals the shape and spread of outcomes.

Mean trajectory versus distribution of trajectories

At each time \(t\), repeated simulations produce values

\[I_1(t),I_2(t),\ldots,I_n(t).\]

The Monte Carlo mean trajectory is

\[\boxed{\widehat{E[I(t)]}=\frac1n\sum_{r=1}^n I_r(t)}.\]

But this average trajectory is only one summary. The simulations can also give quantiles, variances and probabilities of crossing thresholds.

Do not interpret the Monte Carlo mean as the trajectory that will occur. It is an average across many possible trajectories.

Monte Carlo error

A Monte Carlo estimate is itself random because it is based on a finite number of simulations.

For a probability estimate, the approximate standard error is

\[\boxed{\operatorname{SE}(\widehat p)\approx\sqrt{\frac{\widehat p(1-\widehat p)}{n}}}.\]

As \(n\) increases, this uncertainty decreases roughly like

\[\frac1{\sqrt n}.\]
Important consequence. To reduce Monte Carlo error by a factor of 2, we generally need about 4 times as many simulations.

Confidence intervals for a probability

An approximate 95% confidence interval can be written

\[\widehat p\pm1.96\sqrt{\frac{\widehat p(1-\widehat p)}{n}}.\]

For example, if \(\widehat p=0.40\) from \(n=1000\) simulations, then

\[\operatorname{SE}\approx\sqrt{\frac{0.4(0.6)}{1000}}\approx0.0155.\]

The approximate 95% interval is

\[0.40\pm1.96(0.0155),\]

or about

\[(0.370,0.430).\]

For probabilities very near 0 or 1, or for small \(n\), other interval methods can be preferable.

Rare events need many simulations

If an event is very rare, ordinary Monte Carlo can be inefficient.

Example. If the true probability is about \(10^{-4}\), then only around one event would be expected in 10,000 ordinary independent runs. The estimate would be extremely noisy.

Rare-event simulation methods can be used when very small probabilities are scientifically important.

Monte Carlo with Gillespie simulation

In stochastic epidemic modelling, a common workflow is:

define CTMC rates→run Gillespie once→record outcome→repeat many times→estimate probabilities and distributions

Gillespie generates the individual trajectories. Monte Carlo is the repeated-simulation framework used to summarise those trajectories.

Gillespie and Monte Carlo are not the same thing. Gillespie is a method for generating one CTMC trajectory. Monte Carlo uses many stochastic runs—often Gillespie runs—to estimate quantities of interest.

Example: estimating extinction probability

Suppose we start each stochastic epidemic from \(I(0)=2\) infectious individuals and simulate until either infection reaches zero or the epidemic reaches a predefined large-outbreak threshold.

If 640 of 1,000 trajectories reach zero first, then

\[\widehat P(\text{extinction})=\frac{640}{1000}=0.64.\]

The corresponding estimated outbreak probability is

\[1-0.64=0.36.\]

Example: estimating capacity exceedance

Suppose each stochastic epidemic is linked to a hospital-demand model, and let

\[C_{\max}^{(r)}\]

be the peak critical-care occupancy in simulation \(r\). If capacity is \(K\), define

\[Y_r=\begin{cases}1,&C_{\max}^{(r)}>K,\\0,&C_{\max}^{(r)}\le K.\end{cases}\]

Then

\[\boxed{\widehat P(C_{\max}>K)=\frac1n\sum_{r=1}^nY_r}.\]

This converts stochastic epidemic uncertainty directly into a decision-relevant risk measure.

Independent runs matter

Standard Monte Carlo formulas assume that the simulated runs are independent. Each trajectory should therefore use a fresh random sequence.

Using the same random numbers repeatedly would simply reproduce the same trajectory and would not explore the model distribution.

Random seeds and reproducibility

Computer random-number generators are deterministic algorithms that produce sequences designed to behave like random numbers. A random seed determines the sequence.

Using the same seed can reproduce a simulation exactly, which is valuable for debugging and scientific reproducibility. But different Monte Carlo runs must still use appropriately distinct parts of the random-number sequence.

How many simulations are enough?

There is no universal answer. The required number depends on the quantity being estimated and the precision needed.

GoalImplication
rough visual understandinghundreds of runs may sometimes be enough
stable probability estimatesoften requires thousands or more
rare-event probabilitymay require very large simulation numbers or specialised methods
tight confidence intervalrequires larger \(n\)

A useful practice is to monitor whether estimates change materially as more simulations are added.

The complete Monte Carlo workflow

define stochastic model→simulate independently→record outcome→repeat n times→calculate mean / variance / probability→quantify Monte Carlo error
Key idea. Monte Carlo simulation turns a stochastic model into empirical estimates of its probability distribution. One run shows one possibility; many independent runs allow us to estimate expectations, variances, extinction probabilities, outbreak probabilities, threshold risks and other quantities of biological interest.
