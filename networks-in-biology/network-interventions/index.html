Network interventions

A network intervention changes nodes, edges or their states in order to alter a biological process spreading or operating on the network.

Epidemic examples

Possible interventions include vaccination of selected nodes, isolation of infectious individuals, reducing particular contacts or targeting highly connected groups.

Targeted versus random strategies

A random strategy chooses nodes without using network information. A targeted strategy uses features such as degree, community membership or other centrality measures.

Evaluating an intervention

Useful comparisons include outbreak probability, expected epidemic size, peak burden, intervention cost and robustness to uncertainty in the observed network.

Key idea. Network information can help identify interventions that change the pathways through which a biological process propagates.
